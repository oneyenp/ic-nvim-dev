# Neovim 开发仓库初始化设计

## 目标

以参考仓库提交 `e67a9e90168b8b0f1dcfc77cc181dbf754a2347b` 的 LazyVim 配置作为起点，建立配置、构建、插件打包和验证的明确边界。最终目标是一份 EL7 x86_64 兼容发行包，在 EL7 与当前 WSL2 / Ubuntu 26.04 x86_64 实际运行。Ubuntu 24.04 x86_64 列为目标机器，但本阶段不验证。

## 初始化范围

建立根目录说明与约束；将参考配置放在 `config/nvim/`；建立 `build/`、`plugins/`、`scripts/` 和 `dist/` 的职责边界。本阶段不声称已经完成 EL7 构建、插件离线打包或双环境验证。

## 方案

公共配置和锁文件只维护一份。EL7 为二进制和原生组件的构建基线；产物在 EL7 与当前 WSL 分别验证。若实际验证发现原生组件需要平台变体，应保留公共配置，并单独记录平台产物及其依赖。

## 验收

初始化完成时，目录和目标平台状态在 README 与 AGENTS.md 中一致；参考配置位于 `config/nvim/`；生成产物被 Git 忽略；Ubuntu 24.04 明确标记“未验证”。构建和运行验证留待后续实施。
